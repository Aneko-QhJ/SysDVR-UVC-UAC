分组目录按原文件名排序、连续分片，记录原文件长度/摘要、片位置及每组旧合同。校验器同时要求调用方提供原清单摘要和分组目录摘要，严格检查完整覆盖、顺序、类型、分组和片长度；每个缓存组的合同、成员和片摘要也逐项检查。逐片更新SHA256后必须匹配原清单，修改片及其目录摘要仍不能绕过原文件摘要。

`BuildBytes`仅保存不可变字节元组与只读映射。大文件通过`chunks()`读取，`read_small()`拒绝超过1 MiB的完整文件。消费函数只接收缓存和字节参数，不接收来源路径。模型材料化由既有临时目录视图实现完成，消费者不打开材料声明中的路径。

这些限制约束每次声明的字节集合。它们不证明捕获时的OS原子快照、来源持续不变或物理来源。准备程序读取历史封存，当前并未实现面向运行中构建的有界捕获器。原清单不列空目录；本阶段不认证目录语义、descriptor/header/binary关联或编译结果。
