## 只读捕获

- 逐层使用目录描述符及 `O_DIRECTORY | O_NOFOLLOW` 打开源路径，仅读取源 `JOURNAL_COLLECTION_ATTEMPT`。不会扫描或打开源 `execution` 目录。
- 标记和 journal 内普通文件用已打开的描述符读取；比较读取前后文件身份、元数据及目录绑定。源目录、标记名或 journal 在观察期间被替换时保留已捕获字节，标记捕获不稳定，拒绝完整判定。
- journal 缺失、仅有空目录或初始文件损坏时，仍可封存所见状态。符号链接、FIFO、过大文件和不安全节点只记录跳过信息，不读取其内容或解析链接目标。
- 每个文件读取上限 1 MiB，journal 处理上限 512 个节点和 16 MiB 内容；捕获对象及身份状态随取证副本封存。目录枚举的大规模资源压力尚未验证。
- 源标记必须完整绑定声明作业、整数类型 PID、两种构建及 journal 初始副本。即使旧 journal 整包已有 `COMMITTED`，标记损坏或不匹配仍不能判为完整。空标记和半截标记保持占用，不被解释为可重试。
- 动态模式要求调用方持有已退出的对应文件 worker，并绑定作业原始字节与 worker 源码摘要；运行中、未知及其他作业 worker 拒绝。静态模式明确不声称观察到退出。

检查器仅在新取证目录中写入内容、分析和封存。取证副本的 `COMMITTED` 不改变原事务状态；摘要、描述符身份观察和 Python 进程对象均不认证操作系统来源。采集、修复、清理、重试及物理同次运行认证字段仍为 false。

## 已验证场景

| 模型 | 结果 |
| --- | --- |
| 正常源标记和完整日志 | 复核旧冻结假 SDK 链；完整判定成立 |
| 标记写成空文件、半截或完整后退出 | 原始字节保留；无日志时也可封存 |
| journal 目录创建后退出 | 空目录状态保留 |
| attempt 或 SOURCE_ATTEMPT 写成空、半截或完整后退出 | 保留已有字节，不补写缺失副本 |
| 首条事件写成半截或完整后退出 | 保留首事件或部分日志；不当作完整事务 |
| PID 数值相同但写成浮点数 | 拒绝源标记有效判定 |
| 源标记损坏或 PID 不匹配，但旧日志整包完整 | 拒绝提升为完整；原 COMMITTED 字节保留 |
| 标记为符号链接、FIFO 或过大文件 | 仅记录状态，不读取内容 |
| journal 为符号链接或内部有危险/过大节点 | 不跟随链接；危险节点留跳过记录 |
| 源目录、已打开标记名、journal 在读取期间替换 | 3 个模型均捕获不稳定，拒绝完整判定 |
| 运行中、未知、其他 worker；静态模式 | 前三者拒绝，静态模式不声称退出 |

共 26 个主要模型，只有正常场景满足完整判定；14 个直接注入退出场景，另有 5 个危险节点模型复用完整标记后退出的现场，合计 19 个主要场景的 worker 返回 74。26 次再次调用均拒绝，物理原件和日志不因取证或重试被修改；路径替换由审查钩子在私有模型副本中明确注入。7 个篡改归档检查、新 21 项测试及旧 journal 17 项回归通过。

本阶段的 worker 仅用于故障注入：它在独立进程中包装冻结收集器的文件写入和目录建立操作，生成各种引导中断现场。旧 397 项源码与已封存原件不修改，不增加生产收集入口，不运行原生 SDK。

搬移 402 项冻结来源后，重新运行全部模型、替换检查和篡改归档复核，结果一致。Python 文件打开审计禁止原工作区和 `/Volumes`；对 27 次成功取证调用（26 场景加显式静态取证）检查源执行目录打开行为，计数为 0。只读 CLI 的完整、无日志、半截标记、路径替换、静态和坏归档 6 种模式通过。该审计不声称是完整的操作系统访问审计。

首轮成功审查、20 项测试和搬移结果保留在独立摘要中。最终审查增加浮点 PID 拒绝模型及标记 PID 严格整数检查，收紧作业文件读取上限为 1 MiB。
