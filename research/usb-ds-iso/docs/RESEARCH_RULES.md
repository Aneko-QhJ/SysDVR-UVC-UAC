# 当前研究规则（2026-10-27，Asia/Shanghai）

> 流程的最小版本见 [WORKFLOW.md](../WORKFLOW.md)；本文件保留安全边界、证据定义与验收标准。

本规则落实用户本次要求：先不用虚拟机，简化过度严格的研究约束。
它规定后续研究的组织方式；历史实测结论、封存记录和已消耗许可仍按原事实保留。
用户后续的直接要求优先。旧文档的“下一项仅……”描述当时计划，不再自动锁定新研究。

## 当前范围

- 使用现有 Mac，先做能直接缩小问题范围的离线分析和工具准备。
  Linux/虚拟机路线暂缓；本次不安装、启动虚拟机或安排虚拟机 USB 测试。
- 当前按单人、单机、受控来源、单个接收器研究。多控制器并发、恶意篡改防御、
  全面生产者认证、全局持久租约不作为每项诊断的共同前置条件。
  新实验确实涉及这些场景时，再增加相应要求。
- 不再强制先完成 Q2c 设备额度回执协议才能进行任何其他研究。
  按待回答问题选择最小实验；涉及实际额度、复用或新段时，仍需处理相应真实约束。

## 保留的基本边界

1. 原始实机日志、失败样本、固件及现行票据不覆盖。分析结果另存；历史离线副本按
   [存储与留存说明](../STORAGE.md)处理。2026-10-29 用户已明确授权精简历史离线材料，
   已退役条目不保证恢复；保留的原件和封存内容不改写。
2. 不从超时、取消返回、保存成功或安静采样直接推断 I/O 已交还。
   未交还的缓冲区不释放、不覆盖、不复用；完成、取消与本地队列寿命分别处理。
3. 崩溃、设备状态未知、未决 I/O、所有权不明或证据容量不足时停止新提交，
   保留材料并执行适用的收尾。固定时长不被称作已证明的硬截止。
4. 模型、主机观察、设备记录和推断分别表述。正确 raw 不能单独成为严格传输通过；
   新规则不把旧失败改判成功，也不把历史通过描述成当前健康。
5. 操作具体硬件前具备适用范围与现场条件。收到“读卡”默认只读回收、核验身份并安全推出；
   部署按当前已明确授权的范围执行。明确要求读卡、研究、部署一体完成时，在该范围内连续执行。

## 探索与验收分开

| 类型 | 完成标准 |
| --- | --- |
| 探索性诊断 | 获得足以支持或排除一个解释的观察，或明确为何本轮无法区分 |
| 有界能力验证 | 达到预先列出的包数、状态、数据、终结与证据要求；缺项如实标注 |
| 产品验收 | 另行定义持续性、恢复、UVC/UAC、共存、时钟及同步等端到端要求 |

允许探索结果为“有诊断价值、尚不能验收”“证据不完整”或“观察矛盾”。
保存现有材料、说明缺口后即可结束该轮并推进有依据的下一项；不为形式闭合不断扩展通用框架。
安全收尾所需的完成/取消证据仍须处理，不能用“探索模式”跳过未决 I/O。

## 准备与授权

- 每项实验准备一张简短问题卡：问题、变化或假设、采集内容、判别条件、次数/时长上限、
  停止条件。先完成适用准备，再交由用户确认具体硬件操作。
- 编译、适用测试、已有材料分析、计划整理和封存可以在已授权范围内连续完成，
  不逐项询问“是否继续”。物理关机、装卡及开机反馈在需要时合并询问，未知时不推定。
- 后续可以采用明确授权的有界小批次，列明最多次数及允许变化。
  只授权一次时仍只执行一次；旧批次已耗尽时不能恢复旧额度。
- 普通、预期的诊断失败可以按新批次预定规则决定后续步骤；是否允许重复须在启动前明确，
  且状态、资源交还和容量必须满足条件。不在失败后自行添加重试。
- 离线实现失败可直接修正并重跑受影响检查，无需为每次修正重新申请授权。

## 校验与工程范围

- 每次校验应对应一个具体失效点。保留完整来源核对与独立结果验收，
  避免在多个层级重复读取相同的不变材料；运行中关注可变状态、所有权、序号及故障。
- 不要求每项离线诊断复制全部历史或建立新的全量构建。程序、实验配置与证据基线分开管理；
  未变构建在兼容条件满足时可复用。改变校验边界前，先说明输入隔离和变化检测方式。
- 默认使用有限缓冲、固定范围及停止门，按当前问题决定是否研究复用、滚动和长期运行。
  不能仅增加第四轮而忽略现有容量，也无需为不使用复用的实验先证明通用复用协议。
- 测试按改动风险和影响范围选择。覆盖具体边界与已知反例后结束该模型分支；
  不以更多排列数、来源数、检查次数或封存文件数作为主要进展指标。
- 不把“排除所有未来事件”作为有限诊断的完成条件；准确声明观察的历史范围。
  实际释放或复用资源仍须有相应交还依据。
- 优先使用稳定工具和配置。常规通过 fixture 使用临时目录；保留复现输入、结果与必要反例，
  总报告引用明细及摘要，避免重复嵌入大数据。

不通过伪造回执、补次数、改 passed 字段或放宽原件校验来启动。

当前 `remaining=0`、`acquisition_enabled=false`、设备日志不再待回收；本次要求不构成新实测授权。
