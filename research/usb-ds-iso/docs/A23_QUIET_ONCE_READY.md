## 供用户确认的一次执行范围

| 阶段 | 操作及边界 |
| --- | --- |
| 现场起点 | 用户完全关机后取卡，插入 Mac 并报告完成；不凭此前的“可以配合”推断当前已关机/已插卡 |
| 卡核验与备份 | 识别实际 SD，核验四文件基线、回收/备份原件和报告；不符历史 A23 时停止并报告差异 |
| 部署 | 从已封存 sd-review 更新唯一变化的 NSP，核对另外三文件；读回哈希、保存记录并安全弹出 |
| 新记录和预等待 | 明确获准后只签发一份新记录，启动一次捕获并确认 WAITING；此前设备保持关闭 |
| 新设备进程 | 提示用户装回 SD、按现有方式启动 CFW；记录启动动作，等待唯一新接口，USB 重插不能代替新启动 |
| 固定请求 | HS、首次 sequence=1；一次 STATUS→帧号→960×192 ISO 入队→一次 burst→回调，条件满足才 after；lead64，原超时不改 |
| 失败 | 不补发、不补次、不重启工作流；资源不明时保留，不 kill；保存稳定原始材料 |
| 回收 | 提示用户受控关机并确认实际断电，再取卡只读回收同 nonce 文件/日志/报告；保留部分文件，不冒充正常退出 |
| 判读 | 对照 SETUP/早退/准入/sequence/post/ACK 分支表；只报告证据支持的阶段，原根因不预设 |

此范围是一轮独立诊断，不是稳定 UVC 验收。文件基线不符、身份不符、设备数量不符，
或现场无法确认断电时停止对应步骤；不以额外请求、倒数或历史卡状态补足证据。
回退材料恢复的是历史 A23 四文件，实际部署前的备份仍须独立保留。
